1 · Paste webinar details

Accepted input formats

1. Zoom API JSON — the cleanest bulk option. Response from GET /users/{userId}/webinars; recurring occurrences are expanded automatically.

2. Copy Invitation blocks — paste one or many, back to back. Reads Topic, Time, join link, meeting ID and passcode.

3. Simple lines — one webinar per line, pipe-separated:
9/22/2026 | 10:00am | 60 | Fall Parent Info Night | https://…zoom.us/j/123 | Vassar 140 | Optional description
Physical location and description are optional; leave them blank or omit them.

Attendees come from the team defaults on the RSchool Requests tab. If a physical location is given, it takes over the Outlook Location field and the Zoom link stays in the description.
